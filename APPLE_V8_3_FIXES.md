# Apple V8.3 fixes

- Stats and Export sidebar submenus can now be expanded and collapsed independently.
- Aircraft edit now allows changing the registration. The backend updates the aircraft table and every matching logbook flight in one transaction.
- Aircraft edit shows inherited type categories and lets you add/remove extra categories for the individual registration.
- Type edit now shows selectable category choices (including common Single Engine / Multi Engine / Multi Pilot categories) and restores time-field auto-fill controls.
- Attachments now has an Add files / folder action. Choose a flight, then upload one or more files or import every file from a selected folder.
