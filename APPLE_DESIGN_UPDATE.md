# Apple design update

The React application UI has been restyled to match the supplied Apple-style HTML preview while preserving the existing application routes and functionality.

Applied to the real app:
- Apple/SF-style typography and system colors
- Liquid Glass translucent sidebar and top toolbar
- macOS/iOS-style rounded surfaces, cards, controls and focus rings
- Apple-style selected navigation states
- Soft shadows and background radial gradients
- Responsive layout matching the preview breakpoint (800px)
- Light/dark mode retained, with Cmd/Ctrl+J shortcut
- DataGrid/table surfaces updated to the same visual language

`apple-preview.html` is included as the visual reference used for the implementation.
