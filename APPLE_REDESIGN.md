# Apple redesign

This branch/project applies the Apple-style layout used by `apple-preview.html` to the real React frontend.

Main changes:
- 248px glass sidebar / 72px compact mode
- 58px glass top bar
- Apple system typography and spacing
- radial macOS-like background
- translucent cards and soft shadows
- pill buttons and Apple focus rings
- iOS-style switches
- Apple-styled DataGrid/table surfaces
- dynamic page titles/subtitles
- real Logbook summary tiles using backend data (Total, PIC, Multi-engine, IFR)
- Cmd/Ctrl+J theme shortcut

The Go backend/API code is left unchanged.
